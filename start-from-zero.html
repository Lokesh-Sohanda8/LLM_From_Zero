Computers & Problem Solving

Before machines can learn, let's understand what computers do with instructions and information.

Lesson 01

What Is a Computer?

A computer takes information, follows instructions, processes it, and produces a result.

Inputinformation
Processingfollow instructions
Outputresult

At the simplest level, a computer is a machine that takes some input, performs a series of operations on it, and produces an output. A calculator is a tiny example: you give it numbers and an operation, it processes them, and it gives you an answer. Modern computers do this at enormous scale, with much more complicated instructions and much more data.

💡
Think of it like: a very fast worker who never gets tired. You give it information and clear instructions, it follows them exactly, and it gives you a result.

Lesson 02

What Is Data?

Data is information represented in a form a computer can store, process, compare, or learn from.

Real Worldpeople, events, things
Datanumbers, text, images
Useful Information

Data can be almost anything we want a computer to work with: a person's age, a list of prices, a sentence, a photograph, a sound recording, or a table of thousands of customer records. Machine learning is especially dependent on data because the examples a model sees are what allow it to discover patterns.

💡
Think of it like: ingredients in a kitchen. Raw ingredients can be simple, but the cook needs them before a meal can be made. Data is the raw material computers and AI systems work with.

Programs & Algorithms

A computer needs instructions. An algorithm is the plan; a program is one way to express that plan for a machine.

Lesson 03

What Is a Program?

A program is a set of instructions that tells a computer what to do with its input.

Humandefines instructions
Programinstructions + logic
Computerexecutes them

A program is a set of instructions written so a computer can execute them. If you write a program that says, "take these two numbers, add them, and print the result," the computer doesn't need to understand the problem like a human does. It simply follows the instructions you gave it.

💡
Think of it like: a recipe. The recipe tells you what steps to follow, in what order, to turn ingredients into a finished dish. A program does something similar for a computer.
← What Is Data?What Is an Algorithm? →
Lesson 04

What Is an Algorithm?

An algorithm is a step-by-step procedure for solving a problem or completing a task.

Problem
Step 1clear instruction
Step 2another instruction
Solution

An algorithm is the plan behind a solution. It does not have to be code. For example, a recipe is an algorithm for cooking a meal: gather ingredients, boil water, add tea, add milk, and serve. In computing, algorithms can be much more complicated, but the basic idea is the same: break a problem into steps that can be followed.

💡
Think of it like: Google Maps giving you turn-by-turn directions. The destination is the problem, and the sequence of turns is the algorithm for getting there.

From Rules to Learning

This is the key shift: instead of writing every rule ourselves, we can let a machine learn patterns from examples.

Lesson 05

Programming vs. Machine Learning

Traditional programming gives the computer the rules; machine learning gives it examples and lets it discover useful patterns.

TRADITIONAL PROGRAMMING
Rules
Data
Output
VS
MACHINE LEARNING
Data + Examples
Learning
Model / Prediction

In traditional programming, a developer tries to describe the rules directly. For example, you might write: if the temperature is above 30°C, call it hot. In machine learning, you can instead provide many examples such as 35°C → hot, 28°C → warm, and 15°C → cold. The learning system looks for a pattern that explains those examples and can use that pattern on new data.

💡
Think of it like: teaching a child the difference between cats and dogs. You can write hundreds of rules, or you can show many examples and let the child notice the patterns.

Lesson 06

What Is Artificial Intelligence?

Artificial Intelligence is the broad field of building systems that can perform tasks that appear intelligent.

Artificial Intelligence — the broad field
Machine Learning — learns from data
Deep Learning — uses neural networks
NLP — works with language
LLMsyou are heading here

AI is the broadest idea in this course. It includes systems that work with language, images, speech, games, robotics, recommendations, and much more. Machine learning is one way to build AI systems: instead of writing every rule by hand, we let a system learn useful patterns from data. Deep learning is a family of machine-learning methods built around layered neural networks. LLMs sit much further down this tree and focus on language.

💡
Think of it like: a university. AI is the whole university, machine learning is one department, deep learning is a specialization inside it, and LLMs are one specialized area within language.

Lesson 07

What Is Machine Learning?

Machine learning is a way of building systems that improve at a task by learning patterns from examples.

Training Datapast examples
Learningfind patterns
Modellearned pattern
Prediction
↻ training repeats, comparing predictions with known answers and improving the model

A machine-learning model starts with parameters that are not yet useful. During training, it sees examples, makes predictions, measures how wrong those predictions are, and adjusts itself. After many rounds, it can learn patterns that help it make predictions on new data it has not seen before. That basic idea is the foundation underneath neural networks and, eventually, LLMs.

💡
Think of it like: learning to throw darts. You throw, someone tells you that you are too far left, you adjust, and after many attempts your throws become more accurate.

Neural Networks & Language

Now we introduce the machinery underneath modern deep learning and the bridge from numbers to human language.

Lesson 08

What Is Deep Learning?

Deep learning is machine learning built from many layers of neural-network transformations.

Inputraw information
Layer 1
Layer 2
Layer N
Output

Deep learning is not a completely different kind of learning from machine learning. It is a way of doing machine learning with many layers of learned transformations. Early layers can learn simpler patterns, while later layers can combine those patterns into more complex ones. This ability to stack many layers is why deep-learning models can handle complicated inputs such as images, audio, and language.

💡
Think of it like: a team of workers on an assembly line. The first worker makes a simple change, the next builds on it, and after many stations the raw material has become something much more useful.
← What Is Machine Learning?What Is a Neural Network? →
Lesson 09

What Is a Neural Network?

A neural network is a collection of connected mathematical operations whose learned weights let it discover useful patterns.

Inputnumbers
Hidden Layer 1
Hidden Layers
Outputprediction

A neural network takes numbers as input and passes them through layers of simple mathematical operations. The important part is that the network has learned weights that control how strongly different signals influence one another. During training, those weights are adjusted so the network becomes better at its task. Stack enough layers together and the network can learn surprisingly complex patterns.

💡
Think of it like: a chain of filters. Each filter changes the information a little, and the final result is much more useful than the raw input.
← What Is Deep Learning?What Is a Model? →
Lesson 10

What Is a Model?

A model is the learned mathematical system that uses patterns from training to make predictions or produce outputs.

Training Dataexamples
Training
Modellearned parameters
New Input→ output

When people say "the model learned", they mean that training changed a large collection of numbers inside the system. Those learned numbers encode patterns that can be reused later. The trained model can then take a new input and use what it learned to make a prediction, classify something, generate text, or perform another task.

💡
Think of it like: a student who has studied thousands of examples. The student is not carrying every example into the exam; they are using what they learned from those examples to solve a new question.
← What Is a Neural Network?What Are Parameters? →
Lesson 11

What Are Parameters?

Parameters are the learned numbers inside a model that are adjusted during training to improve its behavior.

Prediction
Error / Loss
Update Parameterssmall adjustments
Better Model
↻ repeat many times during training

Parameters are the numbers a model learns. In a neural network, many of them are called weights. At the beginning of training, these numbers are not yet useful. Training repeatedly nudges them so the model's predictions become better. A large language model can contain billions of these learned numbers, but the basic idea is still simple: training changes parameters; inference uses them.

💡
Think of it like: the settings on a huge mixing board. Training keeps adjusting the knobs until the system produces better results for the task it is learning.

Lesson 12

What Is NLP?

Natural Language Processing is the field that helps computers work with human language.

Human Languagewords + context
NLPlanguage → computation
Language Model
Useful Outputanswer, summary, translation

Human language is messy: words can have multiple meanings, sentences depend on context, and the same idea can be expressed in many ways. Natural Language Processing (NLP) is the field that builds methods for working with this language. Modern NLP systems turn text into numerical representations that neural networks can process, then turn the resulting computations back into useful outputs such as answers, summaries, translations, or generated text.

💡
Think of it like: a translator between two worlds: humans communicate with words and meaning, while neural networks operate on numbers. NLP helps bridge that gap.
