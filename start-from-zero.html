Before You Start

You don't need an AI background.

This page starts with computers and gradually builds toward the basic pipeline behind an LLM. You can read the lessons in order, or jump to any concept from the contents rail.

✓ Helpful
  • Curiosity about how AI works
  • Comfort reading simple explanations and diagrams
  • Basic programming is useful, but not required
💡 What you'll build
  • A mental model of AI, ML, and deep learning
  • A basic understanding of neurons, training, and vectors
  • A clear picture of how text becomes something an LLM can process

  • Calculus or linear algebra proofs

Lesson 01

What Is a Computer?

A computer takes information in, processes it according to instructions, and produces a result.

Inputinformation
→
Processinginstructions + computation
→
Outputresult

A computer is a machine that follows instructions to transform input into useful output.

💡
Think of it like: a very fast worker: you give it information and instructions, it does the work, and gives you a result.

Lesson 02

What Is Data?

Data is information represented in a form that a computer can store, process, and analyze.

Real Worldpeople, events, objects
→
Datanumbers, text, images, audio
→
Computerstore + process

Data can be numbers, words, images, audio, video, or structured records. Machine learning depends on data because the model needs examples from which to learn patterns.

💡
Think of it like: a box of ingredients: before you can cook a meal, you need the ingredients in front of you.

Lesson 03

How Does a Computer Represent Information?

Computers ultimately work with numerical representations, even when the original information is text, images, or sound.

Informationtext / image / audio
→
Encodingbits + bytes
→
Numberscomputer representation
→
Processingcomputation

A computer cannot manipulate a word, photograph, or song in the same way a person experiences it. Information is encoded into patterns of bits and bytes that hardware can store and process. You do not need to master binary arithmetic yet; the important idea is that information must be represented in a machine-readable form.

💡
Think of it like: translating a book into a language the worker understands before asking the worker to do anything with it.

Lesson 06

Traditional Programming vs. Machine Learning

Traditional programs are given rules; machine learning systems learn useful patterns from examples.

TraditionalRules + Data
→
Programhand-written logic
→
Outputresult
→
MLData + examples → Model

In traditional programming, a developer explicitly writes the rules. In machine learning, we provide examples and a learning procedure, and the system adjusts internal parameters to capture patterns that can be used on new data.

💡
Think of it like: teaching someone with a rulebook versus showing them many examples and letting them discover the pattern.

Lesson 10

Training vs. Inference

Training changes a model so it learns; inference uses the trained model to produce an output.

Trainingdata → adjustment
→
Trained Modellearned parameters
→
Inferenceinput → output

During training, the model makes predictions, measures error, and updates its parameters. During normal inference, the learned parameters stay fixed while the model processes a new input and generates a result.

💡
Think of it like: training is studying for an exam; inference is taking the exam using what you learned.

Neural Networks

The small mathematical building blocks that eventually become the core of an LLM.

Lesson 11

What Is a Neuron?

A neural-network neuron combines inputs using learned weights, adds a bias, applies an activation function, and produces an output.

Inputsnumbers
→
Weightsimportance
→
Biasadjustment
→
Activationnon-linearity
→
Outputsignal

A neuron is a small mathematical unit. It does not understand a concept by itself; it performs a simple computation. Many such units working together can represent much more complicated patterns.

💡
Think of it like: a small decision maker that considers several signals, gives them different importance, and produces a result.

Lesson 12

What Are Weights and Biases?

Weights control how strongly inputs influence a neuron, while a bias provides a learned offset to its calculation.

Inputx
→
× Weightimportance
→
+ Biasshift
→
Neuroncombined signal

Weights are learned numbers that determine how much each input contributes. Bias gives the neuron an additional adjustable value, allowing the activation to shift even when the inputs are small or zero.

💡
Think of it like: weights are volume knobs for different signals; bias is a small adjustment knob that shifts the whole setting.

What Is an Activation Function?

An activation function adds non-linearity so a neural network can learn more than simple straight-line relationships.

→
Activationnon-linear transformation
→
Outputnew signal

Common activation functions include ReLU, sigmoid, and tanh. You do not need their formulas yet. The key idea is that non-linearity lets stacked layers build increasingly useful and complex transformations.

💡
Think of it like: a filter that changes how strongly a signal is allowed to pass through.

What Is a Neural Network?

A neural network is a collection of interconnected mathematical units arranged in layers that learn useful transformations from data.

Input Layerraw features
→
Hidden Layerslearned transformations
→
Output Layerprediction

Each layer transforms the representation produced by the previous layer. One simple transformation is limited, but many layers can gradually build more useful representations.

💡
Think of it like: an assembly line: each station performs a small operation, and together the stations turn raw material into a finished product.

Deep learning is machine learning that uses neural networks with multiple layers to learn increasingly complex representations.

The word 'deep' refers to the depth created by multiple layers. Deep networks can learn useful features from raw or lightly processed data instead of requiring every feature to be hand-designed.

Think of it like: an assembly line with many stations, where later stations can build on what earlier stations discovered.

Lesson 16

How Does a Neural Network Learn?

Training is a loop: predict, measure the error, trace the error backward, and update the parameters.

Inputexample
→
Networkprediction
→
Losshow wrong?
→
Backpropagationtrace error
→
Updateadjust weights

The network produces a prediction. A loss function measures how far that prediction is from the desired answer. Backpropagation calculates how parameters contributed to the loss, and an optimizer uses that information to update them. The loop repeats over many examples.

💡
Think of it like: a group project post-mortem: after a bad result, you trace back through the decisions and adjust the parts that contributed to the mistake.

Lesson 17

What Is Gradient Descent?

Gradient descent is a method for adjusting model parameters in a direction that reduces the loss.

Current Parameterscurrent position
→
Losshow bad?
→
Gradientdirection of change
→
Updatesmall step
→
Lower Lossimproved model

The gradient gives information about how changing parameters would affect the loss. Gradient descent uses that information to take small steps toward lower loss. The idea matters more here than the calculus behind it.

💡
Think of it like: walking down a hill in fog: you cannot see the whole landscape, but you can feel which direction slopes downward and take a small step.

Lesson 24

What Is Probability?

Probability expresses how likely an event or outcome is, and language models use probabilities to rank possible next tokens.

Contextprompt so far
→
Possible Tokensmany choices
→
Scoresrelative preference
→
Probabilitieslikelihoods

For a context such as 'The cat sat on the', a language model can assign different probabilities to possible next tokens. The model is not simply retrieving a single pre-written answer; it is estimating a distribution over possibilities.

Lesson 25

What Are Logits and Softmax?

A model produces raw scores called logits; softmax converts those scores into a probability distribution.

Model Outputraw scores
→
Logitsunnormalized
→
Softmaxnormalize
→
Probabilitiessum to 1

Logits are the raw numerical scores for possible next tokens. Softmax transforms them into values between 0 and 1 whose total is 1, making them easier to interpret as probabilities.

💡
Think of it like: judges first give contestants raw marks, then a final step turns those marks into normalized percentages.

A language model estimates what language is likely to come next given the context it has seen so far.

A language model learns statistical patterns in sequences of tokens. Given context, it can assign probabilities to possible next tokens. This next-token objective is the central idea behind modern autoregressive LLMs.

Lesson 28

What Is an LLM?

A Large Language Model is a very large neural language model, typically Transformer-based, trained on huge amounts of text to learn language patterns.

Large Datasetmassive text
→
Deep Networkmany parameters
→
Traininglearn patterns
→

The three words matter: 'large' refers to scale, 'language' refers to the kind of data and task, and 'model' refers to the learned system. An LLM is not a database of answers; it is a learned parameterized model that processes token sequences.

💡

Lesson 29

How Does an LLM Generate Text?

An autoregressive LLM generates a response by predicting one token at a time and feeding each new token back into the context.

Promptinput text
→
Tokenizetokens + IDs
→
Embeddingsvectors
→
Transformercontext processing
→
Logitsraw scores
→
Softmaxprobabilities
→
Next Tokenchoose one
→
Repeatuntil done

At a high level, the pipeline is: text becomes tokens, tokens become numerical representations, the Transformer processes the context, the model produces logits for possible next tokens, softmax gives probabilities, and a token is selected. That token is appended to the context and the process repeats.

💡
Think of it like: writing a story one word at a time: after each word, you look at everything written so far and decide what should come next.

Lesson 30

What Is a Transformer?

A Transformer is a neural-network architecture designed to process sequences by allowing each token to use information from other relevant tokens in its context.

Tokens pieces of text
→
Embeddings numerical representations
→
Attention tokens exchange information
→
Feed-Forward refines representations
→
Context-Aware Tokens richer representations

A Transformer is a type of neural-network architecture that became extremely important for modern language models. Instead of processing every word in isolation, it allows tokens to consider other tokens in the sequence and build context-aware representations.

The most important mechanism inside a Transformer is attention. Attention allows a token to determine which other tokens are important to it and gather useful information from them. Transformers also contain feed-forward networks, residual connections, normalization, and other components that help the network learn effectively.

Modern LLMs such as GPT-style models are built using Transformer-based architectures. The exact architecture can differ between models, but the Transformer provides the core machinery for understanding relationships between tokens.

💡
Think of it like: Imagine a group of students reading the same paragraph. Instead of every student reading only their own word, each student can look around the room, decide which other words are important, gather that information, and update their understanding. That is the basic intuition behind attention inside a Transformer.
🚀
The big picture: Tokens become vectors → attention mixes information between tokens → feed-forward networks refine each token's representation → the process repeats through multiple Transformer layers.
